# F407 研究构建的源码归属

ML-KEM 与 ML-DSA 的算法、参数、编码、采样、标准拒绝规则来自标准及生产适配树所保留的上游实现。项目归档记录的 mlkem-native 和 mldsa-native 原生基线版本分别为 `6b12c8cd67e1edd07c43f581386449a6b064e6e2` 与 `7625016fca797896fa7b87cf5455b587a0199682`。生产适配源码另以本树的逐文件 SHA-256 固定；这些经过改写的文件不能表述为与该基线提交逐字节相同。两项目的 LICENSE、META.yml、RELICENSE.md 和原项目的来源记录均在本目录。具体文件以其原有 SPDX 与说明为据。[ML-KEM 许可](https://raw.githubusercontent.com/pq-code-package/mlkem-native/6b12c8cd67e1edd07c43f581386449a6b064e6e2/LICENSE) · [ML-DSA 许可](https://raw.githubusercontent.com/pq-code-package/mldsa-native/7625016fca797896fa7b87cf5455b587a0199682/LICENSE)

在 F407 上执行的 q=3329 正逆 NTT、常量表与有关汇编宏来自 pqm4。q=8380417 的正逆 NTT 与点乘汇编也来自 pqm4。固定提交为 `5e5cc76d0b072ee7077e58afcbc619a1a67a53b4`，实际原始文件及指向的复用源见 `vendor/来源.tsv`。例如多个 KEM 档的 `fastntt.S` 追溯到 ML-KEM-768 的 m4fspeed 源。保留Junhao Huang 等人的 Plantard 算术、以及 Dilithium 汇编文件头的署名与来源说明。pqm4 的根 README 区分实现目录、公共组件及其他代码的许可。核查固定提交的完整 Git 文件树时，所取的 ML-KEM、ML-DSA 实现子目录未见独立 LICENSE/COPYING；部分文件有单件许可，部分只有作者或论文说明。没有将整个算法目录统判为 CC0 或 MIT。逐项许可未确定之处单列留证。[pqm4 固定版本说明](https://raw.githubusercontent.com/mupq/pqm4/5e5cc76d0b072ee7077e58afcbc619a1a67a53b4/README.md) · [算术作者说明](https://junhaohuang.github.io/2022-10-24-Improved-Plantard-Arithmetic/)

本作的实现贡献可按源码逐项追溯。ML-DSA 的配对调度负责按列共用公开矩阵扩展、预计算下一掩码乘积、按原顺序检查候选、限制留存行数并在消费后擦除。ML-KEM 的 combined 实现负责1,024 字节单行累加区（256 个 32 位累加量）、逐行矩阵生成与乘加，以及结合同一条件的短临时区。参数/策略统一入口、独占事务联合区、按生存期推导的资源查询、跨档清理和可重放的比较框架也是本作适配。以上调度在标准算术与上游汇编的基础上实现。板端默认统一候选采用其自身冻结状态的 Keccak；另行比较的 balanced 与 fastfirst 有各自来源、补丁与映像身份。

USB 与启动环境中的 libopencm3 固定提交为 `a3977e14519e4cff8d1feb96445655465797908b`，库内 GPL/LGPL 文本、逐文件 SHA 和来源说明保留在 `target/vendor/libopencm3`。公开 ACVP 向量提交为 `975de31eb83d87039ec88934fdc47d8c312b892d`，各输入的摘要和上游 README（含 License 段落）保留在 `project/tests/vectors/acvp`；期望结果来自冻结向量。Clang 和 GNU as 为外部安装的编译工具，此源码树没有再分发其可执行文件。
