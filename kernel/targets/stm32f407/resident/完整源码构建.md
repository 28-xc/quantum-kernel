# STM32F407 固件

六组参数共用一个 USB 应用和事务区。每组参数提供低内存与高性能两种执行策略。构建名称选择整套固件，运行时策略由请求选择。

| 构建名称 | 单片机算术 | SRAM 上限 | 完整 SRAM | Flash |
|---|---|---:|---:|---:|
| integrated-28 | 32 位校正和半字归约、pqm4 部分变换 | 28672 B | 28504 B | 220580 B |
| independent-28 | 项目实现的两种模数的正逆变换与点乘 | 28672 B | 28504 B | 212132 B |
| integrated-twist | 高性能档增加 ML-DSA 缓存 | 32768 B | 32568 B | 220580 B |

预留调用栈均为 3328 B。完整 SRAM 包括输入、输出、并发传输状态、工作区、栈、中断启动预留和保护区。两种规格的高性能 ML-DSA-44、65、87 分别保留 9/1/0 和 13/6/0 个矩阵项，预留的相邻候选行分别为 4/6/2 和 4/6/7。各构型的三项操作工作区上界在 `identity` 中，对齐偏移及工作区不足时的行为由板上公共查询接口计算。

## 构建

Windows 的 Python 3.11 或更新版本。复建使用 Android NDK 26.1.10909125 的 LLVM 17.0.2 和 GNU Arm Embedded 13.2.rel1 的 GNU assembler 2.41.0.20231009。LLVM 路径指向同时包含 clang、ld.lld、llvm-objcopy 的目录。输出目录位于源码目录外。

```powershell
$env:LLVM_BIN = 'C:\toolchains\llvm\bin'
$env:ARM_AS = 'C:\toolchains\arm-gnu\bin\arm-none-eabi-as.exe'
python -B build.py integrated-28 --output '..\构建输出\高速28'
python -B build.py independent-28 --output '..\构建输出\独立算术28'
python -B build.py integrated-twist --output '..\构建输出\高速32'
```

在 `independent-28` 后加 `--project-polynomials-only` 可从编译与链接中移除全部七个未用到的第三方多项式目标。该选项生成相同的板端 BIN；ELF 的符号表记录这一链接差异。

`algorithm-project` 包含参数化生产实现、API、采样、编码及相邻候选调度源码。`routes` 固定参数、缓存规模、公共函数绑定和原低内存适配体的源码差异。`generators` 生成跨参数共用的 ML-DSA 操作、ML-KEM 变换和模乘。`sources` 保存编译单元、汇编及链接脚本。`configurations` 记录逐项编译、符号绑定和链接顺序。`build.py` 重新展开十二组参数与策略的 C 源码、编译、链接并逐项核对 SHA-256，输出 BIN、ELF、MAP 和重建记录。

## 来源

ML-KEM 和 ML-DSA 的标准参数、编码、采样与拒绝规则来自 FIPS 203 和 FIPS 204。生产代码改编自 mlkem-native 和 mldsa-native，两份基线记录及许可文件见 `algorithm-project/来源与许可`。STM32 USB 使用 libopencm3，来源及逐文件校验见 `algorithm-project/target/vendor/libopencm3`。

三种构建都使用 pqm4 的 Cortex-M 平衡型 Keccak，固定版本为 5e5cc76d0b072ee7077e58afcbc619a1a67a53b4。Keccak 源文件带作者和 CC0 授权。两种高速构建的部分多项式变换来自 pqm4，ML-DSA 的 ntt.S 附有 CC0 声明。该版本的 ML-KEM 汇编、ML-DSA 的 pointwise_mont.s 及部分汇编宏文件未找到逐文件许可声明。来源表保留这一项未确认情况。独立算术构建的最终板端指令使用项目的 q=3329 和 q=8380417 变换与点乘，Keccak 和上述标准算法代码仍按各自来源标注。

## 演示程序绑定

`bind_demo.py` 在原双板演示软件的独立副本中替换 F407 固件和描述文件，并刷新原启动清单。`低内存` 与 `高性能` 对应请求键 `compact` 和 `cached`。应用握手会比对板端重算的完整 Flash SHA-256；单一串口连接可切换六组参数和两种策略。原始 F407 镜像及其完整备份由维护程序核验。
