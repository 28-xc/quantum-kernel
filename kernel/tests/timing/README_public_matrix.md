# 公开矩阵采样的追加归因

该工具用于既有固定输入时序检查的追加分析，保留原始 `INVESTIGATE` 与全部样本。它从明确给定的原检查目录读取协议、实际库、三个种子和九个 `decaps_key` 记录；重放相同的 257 个合法密钥池、输入随机数及每块类别洗牌。仅将各密钥公开部分的 `rho` 用于被计时的采样入口。

先执行 `public_matrix.py prepare --original <原检查目录> --output <新目录> --source-root <冻结源目录>`。默认 `--sampler x1` 必须在原映像中有准确的单路采样符号；`--sampler x4` 则要求准确的四路采样入口，四个输出均与独立 `hashlib.shake_128` 的 SampleNTT 解析核对，包括补位的重复 lane。缺失入口不会自动换库、猜测地址或重编算法作为替代。

`--matrix-rows 0` 表示平铺矩阵诊断；正整数表示按相应行数分块，每个块内不足四项时重复该块最后一个公开索引。冻结 S3 的实际 `stream_indcpa.inc` 使用 rows=2、batch=4，因此 ML-KEM-768 的 6 项块生成 8 个 lane，最后 3 项块生成 4 个 lane。`--grouping-source` 记录被核对的调度源码哈希，`--grouping-scope` 说明它是否对应所测映像的实际分组。不能把用于研究的平铺分组写成另一个候选的完整生产矩阵成本；这些计时也不包含后续布局转换或所有矩阵生命周期开销。

准备完成后，执行该输出目录**已经归档**的 `public_matrix.py collect --original <同目录> --output <同新目录> --token <独占令牌>`。它核对原结果和原始 CSV 的哈希、完整输入 FNV64、逐行类别及公开 rho 池一致性。每组仍保留十万条数据、五个检查点和两种 Welch 统计量，不按是否显著选择种子，不覆盖原始结论。

输出中的 proposals/pairs 是数学上的拒绝采样候选计数，不是实际 SIMD 指令数。squeeze_blocks 是各 lane 的独立需求之和；四路实现一次推进所有 lane，其组内额外轮数取决于最大需求，不能直接把该总和称为实际四路置换调用次数。

公开子路径出现类别差异，连同固定公开部分的秘密输入隔离检查和实际控制流审阅，可支持公开采样归因。
