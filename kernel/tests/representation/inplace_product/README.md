# 原位频域矩阵乘积组件验证

本测试直接包含作品中的 `lc_inplace_ay.h`、`lc_a_planes24.h` 及其实际约减函数，在 AVX2 机器上执行。AArch64 路径直接包含 `lc_speed32_neon.h`、分平面存储头和实际 NEON 约减函数。三个独立程序分别使用 ML-DSA-44、65、87 的矩阵维数。

## 验证内容

测试适配器将已处于 NTT 域的向量送入实际乘积函数。`mld_poly_ntt` 和排列转换在适配器中为空操作，用于注入频域数据。因此，本测试的对象是分平面表示、频域乘积和原位覆盖顺序；NTT、SHAKE、完整签名、实际分配器布局及软件时序性质由各自的测试承担。

对每个频率位置，独立参考结果为

`center_mod_q((sum_l A[l][k][i] * original_y[l][i]) * inverse_mod_q(2^32))`。

参考程序采用有符号 64 位整数，先对点积取模，再乘以模逆，避免中间乘积溢出。参考计算使用保留的原始输入及矩阵，独立于 SIMD Montgomery 约减函数。实际输出先按其允许范围检查，再中心归约后逐项比较。

测试覆盖：

- 公开矩阵的 0、q−1 及 8 位、16 位表示边界；标量和 SIMD 存储交替使用，并逐系数验证实际重构结果。
- NTT 输入严格契约内的最大绝对值 94,279,697，以及额外的 ±94,279,698 边界压力输入。
- 符号交替、行列变化、单列稀疏输入和固定种子的 512 组随机域输入。
- 全部 K×256 个输出、每行末尾的 32 字节保护区、输出和矩阵两端的 64 字节保护区。
- 原始输入和公开矩阵的调用前后逐字节一致性。

三组参数的用例数分别为 697、705、721；合计 2,123 组，逐项比较 3,273,216 个输出系数。固定种子使各后端具有相同输入序列，各参数的结果摘要可用于跨平台核对。结果摘要为 FNV64；文件身份采用独立的 SHA-256。

## 运行

在源码根目录执行，输出目录须为新的目录：

```text
python tests/representation/inplace_product/run.py --cc gcc --backend avx2 --output <result-directory>
```

AArch64 原生环境将 `--backend` 改为 `neon`。默认头文件目录为源码根目录的 `src/dsa_packed`；测试候选头时可通过 `--header-root` 指定覆盖目录，其余头仍从源码目录读取。

运行记录包含实际头文件、测试程序、编译器、预处理结果和可执行文件的 SHA-256，以及编译命令、退出码和每组参数的核对数量。组件程序与预处理文件保存在指定输出目录。临时编译目录也位于该目录。

测试头部的接口适配器仅提供频域数据及完整公开矩阵缓存。AArch64 适配器令矩阵缓存处于已生成状态；若实际代码调用矩阵生成分支，测试立即终止。所有用例均使用确定性或固定种子输入。
