# 共享 Keccak 的机器调用路径复核

`reachability.py` 读取实际映像的符号实体与反汇编，以地址合并别名，只把明确目标的直接调用和尾调用作为图边。它分别寻找保留的 ML-KEM、ML-DSA 命名函数通向同一 `lc_shared_keccakf1600` 实体的路径，并输出每条边的实际指令。

调用路径允许经过 LTO 保留的无家族前缀 helper，只计入有明确目标的实际指令边。检查结果给出两算法族到共享置换的直接可达路径。

`build_reachable.py --source-root <冻结工程目录> --control <现有完整portable对照目录> --output <新目录>` 复用对照的真实编译配方。算法及 SHAKE 前端不修改，构建后仍执行原有标准向量、完整字节差分、置换与 XOF 对照，再运行机器调用图检查。

`test_reachability.py` 包含合成的直接调用、尾调用、helper、地址别名，以及缺少家族路径、仅间接目标、未知目标、假家族别名、重复 provider 等检查。合成结果只验证审查工具逻辑；实际映像结论必须绑定各自二进制、实体表、反汇编和工具文件的 SHA-256。
