# 多项式组件与算法原语

本目录检查两个模数下的多项式运算，并测量明确数学接口的实际函数。`prepare` 构建程序、核对输出与来源；`collect` 保存批量时间和执行条件。

## 参数化标量组件

`include/lc_poly.h` 提供模数3329与8380417下的加法、减法、NTT、INTT、变换域乘法和完整负循环卷积。实现位于 `src/backends/canonical.c` 及相应模板和生成文件，单独形成 `liblc_poly.a`。

每个多项式有256个系数，公开输入输出范围为 `[0,q)`。模3329采用七层配对变换，模8380417采用八层标量变换，逆变换恢复规范系数。乘法输出与输入分离；加减支持逐项原位计算。未知模数返回−1，输出保持原值。

`tools/generate_arithmetic.py` 从标准原根17与1753及位逆序指数生成常数表，支持 `--check` 与 `--output`。实现使用固定宽度整数，完整卷积的64位累加满足 `256*(8380417-1)^2 < 2^55`。准备阶段对两模数各执行10000次变换往返和加减检查、2000次独立学校式卷积比较，并检查非法模数和对象范围。

## 实际算法静态库

`prepare --mode backend` 接受已构建的静态库及其构建记录，核对归档摘要、保留符号、链接映像与反汇编。ML-KEM 优先调用库中的多项式封装；直接调用 AVX2 原语时使用对应 ABI 与常数表。ML-DSA 调用实际多项式函数。声明与布局来自 mlkem-native、mldsa-native 的原头文件，并保留其署名与许可证。

实际后端的表示按以下数学关系核对：

|运算|模3329|模8380417|
|---|---|---|
|NTT|七层不完全变换；AVX2采用自身排列|八层完整变换|
|INTT|输出含 `R=2^16 mod q=2285`|输出含 `R=2^32 mod q=4193792`|
|变换域乘法|分别测试K=2、3、4的缓存多项式内积|单多项式逐点乘法|
|完整环乘|K=2内积入口，第二对输入及缓存置零|两次NTT、逐点乘法、INTT和约减|

变换域乘法带有 `R^-1` 比例，与逆变换的比例抵消。实际系数排列转换后逐项比较独立标量结果，完整乘法与学校式负循环卷积比较。错误输出阳性对照检查比较器，外侧哨兵检查对象边界。两模数的乘法接口分别报告工作量。

## 构建与采集

```text
python -B tools/build_primitives.py prepare --mode canonical --output <新目录> --cc <编译器> --ar <归档器> --nm <nm> --objdump <objdump>
python -B tools/build_primitives.py prepare --mode backend --archive <算法静态库> --build-record <build.xml> --output <另一新目录> --cc <匹配编译器> --ar <归档器> --nm <nm> --objdump <objdump>
python -B tools/build_primitives.py collect --prepared <准备目录/prepared.xml> --output <测量目录> --cpu 0 --session-label primitive-session-01
```

采集前为每批准备100个独立输入状态，计时区间包含100次调用。先预热10批，再测量100批，保存全部读数；进程间使用不同输入种子。正式实验对每个条件启动7个独立采集进程，置信区间以进程为重采样单位。

表内均值为所有批次中每次调用的平均时间。P95、P99描述批均值分布；完整密码操作的单次延迟由 `bench/complete_operations/` 测量。输入恢复及预处理位于原语计时区间外，完整环乘所需的变换、乘法缓存、逆变换和约减按具体调用配方计入。

独立标量组件和算法库原语分别登记。实际原语程序从指定静态归档重新链接，保留优化级别、LTO条件、系数排列、符号和输出检查。记录中的归档、构建与驱动摘要共同确定该次原语实验。
