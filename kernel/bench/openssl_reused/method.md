# 重复使用已导入密钥的 OpenSSL 比较

本组比较保持密钥导入、编码检查、公钥哈希检查及导入时的一致性检查。OpenSSL 在每个批次开始时导入一次密钥，随后重复使用该密钥对象；每次操作仍创建和释放 `EVP_PKEY_CTX`。一次性导入耗时单独记录。密钥生成继续包含生成、编码和对象释放。

LatticeCore 通过序列化密钥接口完成每次调用，包含上下文初始化和接口检查。消息、域分离上下文、随机字节与完整输出沿用序列化比较的配对规则，全部负向功能检查仍在计时前执行。输入参数为 Pure ML-DSA，消息 1024 字节、上下文 0 字节；实际运行参数逐项保存在记录中。

两种调用方式分别描述重复使用已导入密钥及直接处理序列化密钥的服务成本。独立的 `bench/openssl_serialized` 保存每次重新导入密钥的比较入口。本组程序输出导入时间、逐次密码调用时间、原始计时单位和实际加载的 OpenSSL 版本。

`run.py` 默认执行正确性对照；`blocked.py` 在预先固定的配对区组中采集原始时间。编译器、算法库、OpenSSL、输入输出摘要及源文件校验值写入各批次结果。
