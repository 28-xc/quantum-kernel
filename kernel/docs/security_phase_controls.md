# 秘密字段阶段计时与控制实验

全部观察绑定实际执行映像。归档阶段实验分别测量紧凑与速度配置的两个具名映像，每个映像包含660万次阶段调用、180万次完整解封装和30万次阳性对照，共1740万次。原始身份、输入池、预热与预调用、种子和检查点保留于阶段数据入口（见支撑材料实验目录）。最终速度配置另执行180万次完整解封装和30万次阳性对照，共210万次，见当前完整操作数据（见支撑材料实验目录）。两组数据分别保留测量身份。

## 完整解封装

固定公开密文、嵌入公钥及其哈希，分别改变回退秘密z或PKE秘密系数。每种输入域覆盖三个参数、三个预定种子，每族10万次、两类各5万次，每1000次内随机交错各500次。PKE字段在合法模块编码域内独立生成，与固定公钥构成字段隔离输入。每次测量后核对独立SHAKE256(z||ct)结果、输入不变和熵接口零调用。

时间边界包含上下文初始化、公开解封装和清理，使用262144字节固定诊断容量；资源预算由资源数据独立给出。在1万、2.5万、5万、7.5万及10万次调用处计算一阶及合并中心化二阶Welch统计量，阈值为|t|≥4.5。均值差为固定类减变化类。

|实际映像|秘密输入族|超过阈值的族|最大绝对t|阳性检出|

|阶段归档的紧凑映像|18|0|2.438553|3/3|

## 阶段配对与负对照

阶段入口实际执行H(ek)、J(z||ct)、前四个公开矩阵多项式生成及2016字节暂存区清理。输入池含一把固定密钥和256把变化密钥，形成50000次配对访问。六条件原字段组合与八条件双地址实验保留公开字段、秘密字段、仅z、未读取秘密多项式及相同字节假分组。512采用一次同输入预调用，768采用直接调用，各独立重复三次。每500次访问为一完整区组，每重复100组；10000次PCG64分层整块重采样，三重复等权。差值方向为变化输入减固定输入，单位TSC；512主效应平均两种公开条件，768采用固定公开字段。

紧凑配置四项主对比的Holm校正p值依原字段512、z512、原字段768、z768顺序为0.7101、0.7101、0.2438和0.1290；速度配置依同一顺序为1、1、0.6020和1。各组summary.xml保留两个时钟、各次重复、全部控制与地址结果。

紧凑768单独z的合并差值为−72.72662，区间[−140.91933,−8.15114]；相同字节sham为−65.95750，区间[−133.49214,−1.00884]。三次z差值依次为−97.21、−48.09、−72.88，sham为−98.71、−26.36、−72.81，逐次区间均跨零。查看原结果后增加事后解释性z−sham配对，使用相同访问、地址和重复；合并差值−6.76912，区间[−53.77770,41.26702]，三重复分别1.49581、−21.72850、−0.07466，各自区间均跨零。此对比独立保存在posthoc.json，原四项主对比及Holm家族不变。

首次重复的z两地址交互为−254.78，区间[−563.16,−5.43]；未读取秘密多项式对照的交互为−288.17，区间[−551.64,−69.55]。三重复合并后，z−sham的地址交互为49.20，区间[−50.40,148.55]。这些控制结果支持共同位置和时间扰动的解释，区间给出本实验对额外秘密字段效应的分辨范围。

速度配置ML-KEM-768的假分组地址交互为−108.19777，区间[−222.05403,−6.56746]；同条件z−sham合并差值为17.86535，区间[−24.93502,62.49647]，地址交互为18.43351，区间[−65.49601,100.72940]。公开字段与公开矩阵种子的若干对比呈正向区间，各项权重、独立重复及两个时钟均保留在数据中。

## 实际代码及配置范围

阶段以四次固定位置64位读取取得32字节z，PKE秘密多项式不传入此入口。Keccak执行24轮，状态地址固定；矩阵继续采样及筛选位置由公开rho决定。五库四路联合置换均为同一1376字节函数，精确字节身份支持已有四通道来源推导，调用者和公共常量由当前闭包另行核对。

最终紧凑映像与阶段归档紧凑映像的81个可达解封装函数及16个只读对象逐项对应，比较解析实际相对地址和导入目标，两侧分别保留文件摘要。时间分布属于原实际采样映像。最终速度映像的46个可达函数中，五个完整操作函数因链接优化重新生成，其完整操作使用上述210万次新观测；阶段入口及五个可达函数保持对应。`security-code-correspondence-v1`保留机器字节、调用关系、常量和导入项，复算脚本重新解码所附程序并检查全部对应关系。实际加载及IAT检查记录另行保存。

## 历史复算命令

以下三个早期数据目录及对应程序未随包。当前五个 Windows 映像的时序和机器码核验使用复算任务 `five-windows-security-images`。

```text
python data/security-final-images-v1/recompute.py --input data/security-final-images-v1 --output results/security-final-images-recomputed.json
python data/security-final-whole-v1/recompute.py --data data/security-final-whole-v1 --output results/security-whole-recomputed.json
python data/security-code-correspondence-v1/verify.py --data data/security-code-correspondence-v1 --objdump objdump --output results/security-code-checked.json
```

当时使用 Python、NumPy 和 SciPy。复算程序核验全部摘要、原始读数、主统计和独立标记的事后配对结果，与已公布summary.xml逐项比较。

归档数据内的`load-image-reuse.json`限定于其列出的测量映像与部署派生映像。当前配置通过独立机器代码记录关联对应函数，计时分布保留原实际采样身份。当前速度配置的完整操作采用210万次新观察，阶段分析使用已核对的对应代码。顶层复算分别检查这些统计与机器代码关系；软件观察的适用范围为登记的程序、平台和输入分组。
