# AArch64终端演示

演示在Linux AArch64上直接加载紧凑配置与速度配置，执行ML-KEM-512/768/1024和ML-DSA-44/65/87的完整操作及接口检查。密钥由系统随机源生成，终端列出每组参数的操作结果和资源用量。

历史命令（所用 AArch64 终端程序及其输入目录未随包）。

```sh
python3 data/arm-terminal-profiles/lattice_demo --output terminal-result.json
```

原记录中的一次运行完成两种配置的36项正常操作与24项负例检查，并保存各项返回值、实际部署库摘要和资源记录。三项正常操作分别为密钥生成、封装、解封装，或密钥生成、签名、验签。

ML-KEM检查修改密文后的隐式拒绝：解封装返回0，共享秘密逐字节等于标准回退值`SHAKE256(z || c)`的前32字节。ML-DSA修改签名后返回−6，长度错误返回−2。终端最后显示两种配置的工作区、算法内存与程序空间。

终端直接读取所加载库绑定的资源记录，显示工作区、算法栈、上下文、可写全局区、堆和程序空间。算法内存是前五项之和。资源记录关联测量像与部署像的SHA-256，并附装载区等价收据；Python、动态加载器和演示封装计入宿主程序。

原记录所列的终端程序与截图 `images/arm-signing-profiles.png` 未随包。

完整设备接入应用还计入密钥、密文、签名等序列化对象、应用栈及内存池清理。其十种配置的原始配对测量位于`data/arm-application-owner`，资源原始记录位于`data/signing-pipeline-arm/technical-validation`。完整应用数据逐项记录三组参数搭配、两种对象布局与各配置的实际运行内存。
