# 参数裁剪与链接实体

`tools/size_variants.py` 按明确参数集合构建共享库和静态库，并将两种链接方式的完整调用程序纳入映像统计。合法标准参数若未编入当前库，八入口返回 `LC_E_UNSUPPORTED=-8`；选择的参数仍保留全部必要操作。

公开观察数据 `lattice.program_space_observations.v1` 提供各平台实际映像、nm文本、反汇编、保留实体表和逐节统计。共享库、动态链接调用程序与静态整映像分别列出。程序空间计入代码、只读常量、展开和重定位等已分配只读节，以及需要保存初值的可写节；可写全局和线程局部存储另计入运行内存。静态归档的文件字节数、调试节、映像地址跨度和外部运行依赖单独登记。

```text
python -B tools/recompute_program_space.py --observations <公开目录/observations.xml> --output <新复算.xml>
```

复算程序从实际 PE/ELF 字节重读节表并重新汇总，从原始 nm 输出重建实体表，再从同映像反汇编复算两算法族至共享置换函数的直接调用或尾调用路径。每个输入文件均按公开相对路径与 SHA-256 绑定。objdump 文件名标题改为统一的 `image`，指令和符号行完整保留，原始反汇编摘要另列。

跨算法共享保留SHAKE上下文、吸收率和域分离，为25×64位状态置换提供共同入口。比较采用同平台、同LTO条件，按实际映像记录字节增减。链接器可能已合并两个命名空间中的相同函数，实体核验据此分别检查符号地址、机器码和调用路径。缺少可靠函数长度的COFF记录使用`null`；间接调用与内联结构按实际反汇编登记。

普通六参数构建与参数裁剪构建使用各自的映像摘要。裁剪入口增加参数支持检查，即使选择全部参数，其代码布局和程序空间仍单独测量。性能表、资源表与程序空间通过同一库摘要关联，裁剪结果按各自功能范围比较。
