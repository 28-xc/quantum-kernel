# 完整操作的指令采样数据

Windows 采样器执行六组参数的密钥生成、封装/解封装或签名/验签，共十八项完整操作。密码工作线程与观察线程分别固定到不同逻辑处理器。观察线程每毫秒读取自身工作线程的指令地址，将落在密码库内的地址转换为映像相对偏移；库外样本记为零。每一项采样前后均检查密码操作结果，并验证实际加载的密码库和 OpenSSL 版本。

公开观察清单 `lattice.instruction_samples.windows.v1` 保存程序身份、操作参数、迭代数、线程位置、样本数量以及原始 CSV 和反汇编映射的 SHA-256。CSV 保留采集顺序、观察时钟及每条指令偏移。映射保留实际指令、反汇编标签及同地址别名。主程序工作区容量为 262144 字节，消息为 1024 字节，上下文长度为零；带密钥输入的操作采用固定输入密钥，各格逐次生成操作所需的测试随机量。

每格执行20000次完整调用。小缓存与紧凑两种实际库覆盖全部十八项操作，共36个单元；每个单元保留其全部样本数量与指令位置。采样读取时短暂停顿工作线程，因此图表使用位置样本数描述热点；完整操作时延和加速比来自独立配对计时数据。

`tools/recompute_profiling.py` 从公开CSV重新统计每格的指令、标签与类别次数，核验映像范围、时间顺序、SHA-256、全十八项操作及库外样本。结果按编码与表示、SHAKE/Keccak、采样、NTT/INTT、清理与空间管理、多项式算术、协议及其他内联代码分组；具体匹配规则随结果导出。标签表示机器指令所在的反汇编块，内联指令随其所在块统计。图表显示原始类别计数，库外样本单列。

复算入口接受公开观察清单和一个新的输出文件：

```
python tools/recompute_profiling.py <observations.xml> --output <recomputed.xml>
```

该工具使用 Python 标准库。公开数据及代码即可完成原始样本校验与统计复算。
