# 算术原语数据

原语数据保存实际静态归档、构建记录、驱动身份、数学接口和全部批次。每批100个输入状态在计时前准备并恢复；计时区间包含100次调用。每个独立进程预热10批、测量100批，正式统计按协议中的独立进程数汇总。

参数化标量组件采用规范剩余类和标准系数顺序。实际算法后端保留对应NTT排列与Montgomery比例，变换后通过明确转换与独立结果比较。ML-KEM变换域乘法分别测K=2、3、4缓存内积，ML-DSA测单多项式逐点乘法；完整环乘另外计入正逆变换和约减。

`lattice.primitive_samples_observations.v1`登记实际采集条件；对应统计保存全部批均值的均值、中位数、P95、P99及独立进程重采样区间。百分位描述批均值分布，完整密码操作的单次延迟由十八项实验记录。

公开读取器 `publicschemas/primitive_samples_v1.py`核对原始CSV、顺序、预热、调用次数、时钟频率和文件摘要，复算数值。构建与采集方法见 `bench/primitive/README.md`。每个数据集保留实际数学工作量、输入范围与重链接身份。
