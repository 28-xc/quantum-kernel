# 按资源预算与业务负载选择配置

本地演示提供密码核心与完整设备接入流程两类选择。每项选择都核对平台、实际库文件摘要和已测资源，结果包含全部可行配置与超额原因，可导出JSON复算。

密码核心按六组参数、十八项操作共同预留内存。用户为各项操作填写调用次数，选择器计算各完整操作均值与次数的乘积之和，再除以总调用次数，得到平均密码服务时间。签名为主、验签为主与解封装为主的预设会显示具体次数，也支持自定比例。程序空间和内存仍对应完整六参数库。

设备接入流程依次完成公钥签发、验签与密钥建立。选择条件包括参数搭配、每批1或200个流程、签发身份的复用方式、应用内存及程序空间上限。时间取自包含初始化、身份准备、全部流程和最终清理的实测批次；内存包含固定池、序列化对象、栈、全局区、TLS与外部堆。选择器按完整批次均值排序，保留各项95%区间、库文件摘要、应用文件摘要及原始数据身份。

API入口：

- `/api/budget`：平台、资源研究、计时研究及预算字段；可追加 `operation_counts`，内容为参数、操作与调用次数的JSON数组。操作编号0为密钥生成，1为封装或签名，2为解封装或验签。
- `/api/application-budget`：`platform`、`kem`、`dsa`、`flows`、`fresh_identity`、`ram_bytes`、`program_bytes`。`fresh_identity=0`表示批内复用身份，1表示每流程重建。返回同批测量中满足预算的完整应用配置。

密码服务时间适合分析操作调用比例；设备接入批次耗时用于该完整应用的配置比较。两类结果各自保留对应时间与资源范围。
