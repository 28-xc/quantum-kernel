# 源码、实验工具与技术数据

支撑材料分为源码、程序与固件、实验数据与复现、实板与仿真证据。实际程序与测量数据通过库文件 SHA-256 关联；每个实验还登记对应驱动、配置和统计程序。

## 编译输入

`tools/build.py bundle` 根据显式源码清单复制核心 C 与汇编文件、构建工具、目标运行时、功能检查、标准向量和上游许可。`plan` 对当前文件逐项计算摘要，`build` 按该清单编译。编译器依赖记录用于核对实际参与构建的文件。

PQClean 参考代码使用独立来源清单，保留官方文件、适配器、随机源包装、构建器和测试入口。文件的相对路径、官方 Git 对象及 SHA-256 均在清单中登记。每种构建单独执行适用功能检查。

## 数据与统计

完整操作数据包含全部预热与测量行，保存均值、中位数、P95、P99、极值和配对区组区间。统计附件保留原始 CSV、观察清单与统计实现。原语按批均值汇总，完整应用按一次接入流程汇总，指令采样按位置数量汇总，各自采用对应实验单位。

`publicschemas/` 提供数据结构校验与公开读取器。数据清单绑定配置、平台、实际映像和源文件摘要；容量不足、异常退出、阳性对照及较慢样本保留原状态。界面查询与导出使用同一组已登记数据。

完整统计与绘图复算使用Python 3.13、NumPy 2.2.5、SciPy 1.18.1和Matplotlib 3.10.9；随包离线入口提供NumPy统计。`docs/analysis_requirements.txt`列出源码环境依赖。Windows附件提供官方嵌入式Python及离线NumPy wheel，原件和展开文件的摘要及许可证记录在运行时清单中。

本地服务加载需要NumPy的数据读取器时，从随包且经SHA-256核验的wheel准备独立依赖目录；全部过程离线完成。源码、系统Python和用户全局软件配置保持独立。运行与复算的具体命令见附件使用说明及对应实验目录。
