# 共同上下文数据

共同上下文试验在同一实际库、上下文和工作区内交错执行六组参数的十八项操作，并检查失败后的恢复。每份观察绑定对应资源文件和算法库摘要。

固定容量验证包括24个种子和两种参数顺序。容量边界另外运行正常W与W−32档位，记录返回码、输出比较、对象哨兵、释放清理及恢复结果。多档预算检查与仪器控制分别保留；故意栈越界和区外堆分配记录按控制条件解释。

公开读取器重新检查操作次序、同一context与arena身份、容量、水位、初始化次数、返回和恢复。部署容量采用同一映像的共同工作区与栈，各原始试验均参与核对。

```text
python -B tools/recompute_common_context.py --observations <observations.xml> --resources <resources.xml> --output <新的结果.xml>
```

方法文件按相对路径和SHA-256保存，包含探针、平台栈入口与所需声明。公共采集工具位于 `tests/resources/`。源文件身份、资源记录和实际库共同确定该实验。

预留容量与观测水位分别列出。固定资源之和描述调用方需要准备的空间；工作区和栈水位描述给定种子与调用序列中的使用情况。秘密擦除按已分配对象和指定范围检查；操作系统栈映射和物理驻留量由相应系统指标记录。
