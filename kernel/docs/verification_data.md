# 功能验证与复算

功能数据按实际程序、测试套件和输入条件记录。无插桩部署库、独立参考实现、插桩库及目标ELF分别绑定文件摘要。标准向量、完整流程差分、签名字节、接口边界、容量恢复、秘密标记与OpenSSL互操作分别统计。

## 覆盖量

适用ACVP向量使用向量快照、测试组和测试编号标识。相同向量在多个实现执行时分别记录执行次数；独立向量数量与实际执行次数分开。公开接口实现Pure ML-DSA和ML-KEM的指定标准操作，数据保留适用范围分类。

完整流程比较公钥、私钥、密文、共享秘密、签名及随机字节请求顺序。签名专项改变消息、上下文和密钥，逐字比较完整输出并验签。正常容量检查包含连续调用、参数交错、独立上下文并发、容量不足、随机源错误、清理与恢复。

ML-KEM等长修改密文按标准返回替代秘密与成功码；私钥中的公钥哈希错误进入显式错误路径。ML-DSA修改签名返回拒绝。这些结果按各自语义核对。

Windows五种部署配置另逐一执行固定Wycheproof向量、Go与liboqs互操作、公开密钥编码边界及共同上下文连续操作。当前源组件检查覆盖24位表示、紧凑编码、位图、固定域辅助函数、跨尝试采样及nonce边界。融合编码检查实际辅助函数的16,761,088个系数输入，记录被测源和编译条件。

## 内存与秘密依赖检查

ASan和UBSan对应实际插桩构建，记录检测器阳性对照。秘密标记实验在随机回调输出和序列化私钥处设置标记，在标准公开输出完成后释放标记；同一驱动的分支谓词对照检查检测能力。普通内存访问检查与显式秘密标记实验保留各自条件及结果。

Cortex-M4与RV32目标程序实际执行六参数的标准向量子集、接口边界和恢复检查，保存控制台、ELF、链接脚本及内存账本。代码映射、可写预留和观察栈峰值分别列出。

## 重新检查

各套件的公开清单列出程序摘要、原始文件、条件和统计入口。复算程序核对记录结构、文件摘要与输入顺序，重新统计结果；缺失、重复或不一致记录产生具体错误。重新编译运行使用当前源码、工具链和新的输出目录。

主要入口包括 `tests/platform/`、`tests/normal_capacity/`、`tests/compact_memory/`、`tests/pqclean/` 与 `tools/build_targets.py`。紧凑验证材料可由 `tests/compact_memory/audit_validation.py` 读取观察索引重新核对。性能、资源和软件时序分别使用其数据协议。

## 签名资源配置的独立验证

`data/verification-signing-pipeline`保存两平台五种部署配置的十份生产库验证，分别覆盖紧凑、48项矩阵缓存、56项矩阵缓存、32位矩阵缓存与速度配置。每份库分别完成645项适用标准向量、1200组完整序列、900组签名字节比较、864项容量与恢复记录，以及3600次OpenSSL互操作。向量数据同时保留405条接口范围分类。AArch64的插桩、秘密传播与注解等价记录分别绑定对应插桩库和生产库。

秘密传播测试公开密钥编码全区域检查后的单个合法性结果。完整秘密密钥及中间数据仍受标记跟踪，测试注解仅改变检测器的公开信息模型。公开包保留该模型的原始诊断、差异文件和输出等价检查。[阶段计时与控制实验](security_phase_controls.md)说明地址、顺序、秘密字段与尾部观察的对应关系；[矩阵缓存与算术验证](signing_arithmetic.md)列出整数界和两个指令集的固定测试域。

统一验证目录提供`observations.xml`、`summary.xml`及`recompute.py`，按生产库身份重新核对计数、日志和文件摘要。完整科学复算入口同时覆盖这些材料。

矩阵分平面和频域原位乘积使用`tests/representation/inplace_product/`，分别在AVX2与NEON上核对实际辅助函数的全部输出与保护区。`tests/owner_boundaries/`观察十八项操作的分配位置、容量错误、释放前清理和同上下文恢复；直接链接原静态库的独立程序提供完整输出对照。组件测试、生命周期测试与生产库标准验证分别记录所用程序身份。

Windows合法系数稀疏乘法组件使用实际生产头完成24576例、6291456个输出系数比较，包含14592例标准编码和9984例非法编码回退。低层直接入口另保留72例非法编码及9例标准编码的完整签名字节对照。紧凑、48项缓存与速度配置分别记录2065、3116和3116次拒绝尝试，完整借用响应区在重试前全部清零；单字节残留正对照验证观察器确实能检出错误。
