# 远端与开发板连接配置

[Quantum Kernel 使用说明](<../../../03_复现环境与运行程序/软件演示程序/使用说明.md>)中有 Windows、Linux AArch64、STM32F407 和 CH32V307 的操作入口。

## 外部连接文件

`%USERPROFILE%\.lattice-live\arm.xml` 配置 ARM 主机，`board.xml` 可覆盖 CH32V307 默认连接。ARM 字段见 `PLATFORM_API.md`。CH32V307 的连接文件由 `tools/demo_board_config.py` 根据驱动、ELF、板端 HELLO 和计时凭据生成。

## CH32V307 命令行

```powershell
python -B tools/demo_unified.py --ch32-probe
python -B tools/demo_unified.py --ch32-run 512 --output-xlsx D:\\临时\\封装结果.xlsx
```
